# 无双深渊 阵容助手

《无双深渊》的武将搭配查询工具，可在电脑或手机浏览器中使用。

原版阵容助手由 **xie1103236736** 发布。本项目沿用原版的武将数据、可用随行列表和阵容推荐，在此基础上增加了两个功能。[原作者与原项目](https://github.com/xie1103236736/abyssal-gem-guide)

- **同行武将推荐**　选定主将后，根据主将的印记和特性推荐同行武将。可以分别切换主将和同行的突破状态，点开名字查看匹配的同行特性原文。
- **随行武将查询**　固定主将后，在第二个搜索框输入其他武将的名字，即可查看对方是否在当前主将的可用随行列表中。
