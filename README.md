# 无双深渊 · 随行推荐助手

《无双深渊》的武将搭配查询工具，可在电脑或手机浏览器中使用。[打开网页版](https://liuliusizhuo.github.io/abyssal-lineup/)

原版阵容助手由 **xie1103236736** 发布。本项目沿用原版的武将数据、可用随行列表和阵容推荐，在此基础上增加了同行推荐和随行查询。[原作者与原项目](https://github.com/xie1103236736/abyssal-gem-guide)

## 使用方法

- **同行武将推荐**　选定主将后，根据主将的印记和特性推荐同行武将。可以分别切换主将和同行的突破状态，点开名字查看匹配的同行特性原文。
- **随行武将查询**　固定主将后，在「武将配合查询」里输入其他武将的名字。若对方可用，点名字即可跳到下方的武将详情，查看随行效果。想对比同一武将的两种形态，可以只搜本名，例如「孙尚香」。

## 更新记录

### 2026-11-24 · 随行查询与武将数据校正

- 查询结果用「破盾」「攻击」「辅助」标明可用随行的作用。只有一个突破阶段能配合时，名字后才显示「仅突破前」或「仅突破后」。两个阶段都能配合时省略标签。如果突破会改变作用，结果中会分别注明。
- 点击查询结果中可用武将的名字，会跳到并展开该武将的随行详情，方便对照突破前后的效果。
- 将 14 名异化英豪统一标为「（异化）」，例如孙尚香（异化）。董卓、张角、吕布、紫鸾的《起源》联动版本保留「（起源）」。两个搜索框都支持直接搜「异化」或「起源」，也支持用半角括号输入全名。
- 按游戏简中原文校正陆逊的固有战法「异常状态附加概率变为100%」。突破前对吴英豪生效，突破后也对大将军生效。
- 修正赵云（异化）的护盾说明。突破前每击破 100 名敌人触发，突破后为 70 名，护盾均持续 10 秒。另校正了「赤兔马」「主君之盾」等名称，以及甘宁、赵云和黑田官兵卫的同行特性中误连在一起的印记条件。
